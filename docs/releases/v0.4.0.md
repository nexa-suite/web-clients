**Status: local release candidate, unpublished.** Prepared on 2026-10-29 from Web `develop` at `0fed93f32c11f4f991be72e01f5bcc26d6551e54`. No `v0.4.0` tag or GitHub Release has been created.

## Scope

- Align the existing Buyer Portal draft date-selection flow with the API-owned delivery lead policy. The page reads the server minimum and blocks draft setup if the policy cannot be read or the selected date is earlier than that minimum.
- The API remains authoritative for validation when draft commands are submitted.

## API compatibility

The client expects `GET /api/v1/buyer/delivery-lead-policy` with these response fields:

```json
{
  "minimumDeliveryLeadBusinessDays": 5,
  "minimumAllowedDeliveryDate": "YYYY-MM-DD",
  "timezone": "America/Lima"
}
```

The integrated Web CI source at `0fed93f32c11f4f991be72e01f5bcc26d6551e54` pins API candidate `b8d8bd0574c95631d472380804c1d1e4e33de62a` for its API integration job. This is the API v2.0.0 candidate source, not a published API release. API `v1.2.0` does not include this policy endpoint, so it does not support the Buyer draft workflow in this Web source.

The API contract defines five Monday-to-Friday business days in `America/Lima`, excludes the current Lima date, has no holiday calendar, and leaves weekend delivery dates eligible once the minimum is met. This summary describes the API candidate contract; the local preparation did not run a separate connected integration. Integrated-source CI evidence is listed below.
