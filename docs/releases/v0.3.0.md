# Nexa Web Clients v0.3.0 — source release

**Status: published source release (2026-10-29 UTC).** Based on the integrated academic checkpoint. See the [GitHub Release](https://github.com/nexa-suite/web-clients/releases/tag/v0.3.0). This source checkpoint does not establish Product or System Acceptance.

## Scope in this snapshot

- Platform contains scoped workflows for customer accounts and addresses, Buyer relationships, catalog references and administration, and Sales review of proposed Purchase Request changes.
- Platform contains a public organization-registration draft and activation-request flow. Final submission remains blocked unless an authorized `REGISTRATION_TERMS_PUBLICATION` is configured; submitting a request does not provision an immediately usable Tenant.
- Buyer Portal contains server-backed catalog references, public product imagery, Purchase Request detail and responses to proposed material changes.
- Buyer draft saving preserves selections edited or added while an earlier save is pending; leaving an existing draft before loading completes also preserves the selection.
- Platform contains scoped inventory consultation and inbound receiving. Optional photo evidence is Warehouse-scoped and must reach scanner status `AVAILABLE` before its ID is submitted with a receipt. Temperature policy and HOLD decisions remain API-owned.
- Visible order and delivery projections refresh from API reads. Buyer live location is limited to an active scoped Delivery; map rendering requires explicit provider configuration.
- Navigation and actions use server-issued permissions. Retry identities and frozen command payloads are retained for uncertain outcomes.
- The latest checkpoint defers the Buyer Favorites route and page. This source release does not claim a supported end-to-end Favorites workflow.

These bullets describe source present in this snapshot, not complete or accepted Product behavior.
